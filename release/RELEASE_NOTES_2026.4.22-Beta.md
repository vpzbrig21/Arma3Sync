# Arma3Sync 2026.4.22 Beta

## Improved

- Discord emoji picker previews Unicode emoji with bundled Twemoji 17.0.3 color artwork where available.
- Unicode emoji newer than the bundled artwork continue to use the installed emoji font as a fallback.
