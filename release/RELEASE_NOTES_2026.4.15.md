# Arma3Sync 2026.4.15

## Added

- The normal uninstaller now asks whether personal Arma3Sync data should be
  removed.
- The safe default keeps profiles, settings, repository definitions, cache and
  logs so a later reinstall can continue without reconfiguration.
- Silent uninstalls keep personal data by default; explicit removal is
  available through `/DELETEUSERDATA`.

## Compatibility

- Portable installation data is included in the explicit data-removal option.
- The installer publisher remains `Virtuelle Panzerbrigade 21 (vPzBrig21)`.
- The package identifier remains `vPzBrig21.Arma3Sync`.
